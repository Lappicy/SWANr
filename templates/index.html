Manual do Usuário

Como utilizar a Plataforma

Siga os passos abaixo para realizar o download dos dados:

  • Passo 1: Selecione o Produto e Subproduto desejado.
  • Passo 2: Defina sua Área de Interesse (Upload, Estado ou Desenho no mapa).
  • Passo 3: Escolha a Data Inicial e a Data Final.
  • Passo 4: Clique em Consultar. O sistema buscará os arquivos na NASA.
  • Passo 5: Selecione os arquivos e clique em Baixar. Uma janela se abrirá para escolher a pasta.
